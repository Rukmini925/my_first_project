# Student Marks Calculator

A simple web-based application that calculates total marks, average marks, and grades of students using HTML, CSS, and JavaScript.

---

## Project Description

The Student Marks Calculator is designed to help users calculate student performance easily. Users can enter marks for three subjects, and the system automatically calculates:

- Total Marks
- Average Marks
- Grade

This project was developed to practice:
- GitHub workflow
- HTML, CSS, JavaScript
- Branching and Pull Requests
- GitHub Actions

---

## Features

✅ Student name input  
✅ Marks calculation  
✅ Average calculation
